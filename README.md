# 人脸识别考勤系统

基于 **人脸识别 + 拍照台账** 的工地考勤处理系统。

每天工人开工 / 收工时用相机拍一张照片（照片文件名含拍摄人姓名和拍摄时间，如 `储少球 2026_06_08 09_05_17 开(收)工汇报.jpg`），系统通过 **InsightFace** 人脸识别确认照片中的人员，再结合工作安排表、项目信息表等 Excel，自动生成一套考勤报表（表1 ~ 表10），并对 **缺勤、多报、漏报、项目不匹配** 等异常情况自动检验，输出"人工复核提示文档"供管理员核对。

## 使用说明（快速上手）

### 1. 启动系统

双击 **`启动网页.bat`** → 自动启动服务并打开浏览器（`http://localhost:5000`）。

> 工程自带 `runtime/`（embeddable Python 3.12 + 全部依赖 + 人脸模型，约 1GB），**无需安装 Python**，整个工程文件夹复制到任意 Windows 电脑即可运行。

### 2. 网页操作流程（6 步向导）

1. **人脸识别**：拖拽上传 Ref_Figure 人脸库 / Target_Figure 出工照片 → 点「开始人脸识别」→ 生成 `output/00_程序人脸识别结果.xlsx`（后台线程运行，页面实时刷新日志）
2. **上传输入表**：先上传 4 个输入表（照片台账表 / 工作安排表 / 人员分类表 / 考勤模板），人工复核需要基于 `01_照片台账表` 匹配人员名单
3. **人工复核未识别人员**：逐张展示未识别(Unknown)人脸的出工照片，红色框选未识别人脸，旁边显示照片人员名单（自动匹配 `input/01_照片台账表.xlsx` 中对应照片的人员名单）/ 拍照人（不在照片中，不算异常）/ 识别结果 / 差异提示，每个未识别框可填姓名（可留空跳过）→ 点「确认本张」自动写回 `00_`，后续表3~表10 直接使用修正后的姓名
4. **生成项目信息表**：上传 3 张表（`04_工地项目统计` / `06_周工作安排表` / `07_周工作计划表`）→ 点「生成项目信息表」→ 模糊/一对多/新增匹配会弹窗逐条人工确认 → 输出 `output/000_项目信息表.xlsx`（一个周期生成一次即可，不需要时可跳过本步）
5. **生成表格**：一键依次生成表1~表10，生成到关键表时自动弹出查看/编辑界面——**表1** 弹出预览并红色高亮开工/收工汇报异常；**05/06** 弹出核对界面（内联展示核对信息错误文档 + 可直接在网页上修改表格：改单元格 / 增行 / 删行；05 的「加班时长确认-人工审核」列空值显示「待确认」供填写确认，06 该列锁定不可改，可修改的是开工/收工项目名与简称），点「保存并继续」写回 output 对应表格后继续
6. **完成下载**：全部完成后下载「08_09_10_最终考勤表.xlsx」（**一个文件三个子表**：表8工程考勤表 / 表9外协考勤表1 / 表10外协考勤表2，合并单元格格式保留，与输入模板同构）

### 3. 终止服务

| 方式 | 操作 |
| ---- | ---- |
| ① 关闭窗口 | 关闭启动时出现的**黑色命令行窗口**（标题：`Face Recognition Server - Close this window to STOP`），点右上角 ✕ 即可 |
| ② 一键停止 | 双击 **`停止服务.bat`**，自动杀掉占用端口 5000 的服务 |

> **注意**：关浏览器标签 ≠ 停服务，服务一直活在黑窗口里。验证是否已停：浏览器访问 `http://localhost:5000`，打不开（拒绝连接）即已停止。

### 4. 常见问题

- **`DLL load failed`**（目标电脑）→ 安装一次 [VC++ 2015-2022 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)
- **端口 5000 被占用 / 启动失败** → 先双击 `停止服务.bat`，再重新启动
- **模型与后端**：便携版自动把模型指到 `runtime/insightface_home`（环境变量 `INSIGHTFACE_HOME`），推理后端自动检测 CUDA → DirectML → CPU，无 GPU 机器也能跑

### 5. 开发环境启动（不用便携版时）

> 需用 **AI_PY312** 环境（已装 insightface/cv2）。若未装 Flask：`C:/Users/29037/.conda/envs/AI_PY312/python.exe -m pip install flask`

```bash
# Web 界面
C:/Users/29037/.conda/envs/AI_PY312/python.exe web_show/web_app.py

# 命令行（人脸识别 + 生成表1~表10）
C:/Users/29037/.conda/envs/AI_PY312/python.exe main/main.py
```

## 便携运行时 runtime/（已内置，无需安装）

工程自带便携运行时，把 **Python 解释器 + 全部依赖 + 人脸模型** 都装进了 `runtime/`，所以任意 Windows 电脑**无需安装 Python**，整个文件夹复制即用。

```
runtime/
├── python/                     # embeddable Python 3.12.10 + 已装好的全部依赖
│   ├── python.exe              #   Python 解释器（免安装）
│   ├── msvcp140.dll 等         #   VC++ 运行库 DLL（已内置，避免 DLL load failed）
│   └── Lib/site-packages/      #   全部依赖包
├── insightface_home/
│   └── models/buffalo_l/       #   人脸识别模型（约 326MB，离线使用）
└── requirements-lock.txt       #   依赖锁定文件（重建运行时用）
```

正常情况下**什么都不用装**。仅当 `runtime/python/` 损坏、或要在其他环境重建时，才执行：

```bash
runtime\python\python.exe -m pip install -r runtime\requirements-lock.txt
```

## 核心数据流

```
Ref_Figure/ 人脸库  +  Target_Figure/ 当日照片
   │  main/main.py  人脸识别 (InsightFace)
   ▼
00_程序人脸识别结果.xlsx
   │
   ├─ get_table3 → 表3 ─ get_table4 → 表4 ──┐
照片台账表 ─ get_table1 → 表1 ─────────────┤
工作安排表 ─ get_table2 → 表2 ─────────────┘
                                                    get_table5
                                                    ↓ 表1 vs 表4
                                   05_该日出工人员表 + 核对信息错误文档1
                                                    get_table6
                                                    ↓ 05_ vs 表2
                                   06_全体人员出工情况表 + 核对信息错误文档2
06_ + 03_人员分类表 ─ get_table7 → 表7 出工地点及时长统计表
表7 + 考勤模板 ─ get_table8_9_10 → 表8/表9/表10 最终考勤表
```

> **注意**：表5（05_该日出工人员表）、表6（06_全体人员出工情况表）由 `get_table5` / `get_table6` 自动生成，不再需要手工上传；`核对信息错误文档1/2` 在有异常时生成，供人工核对修正。

## 程序职责详解

### 1. 人脸识别核心包 `face_app/`

| 文件               | 职责                                                                                                                                                                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `face_engine.py` | InsightFace 封装：`init_face_app`（加载 `buffalo_l` 模型）、`enroll_faces`（录入 Ref_Figure 人脸库）、`match_face`/`cosine_similarity`（余弦相似度比对，低于阈值判为 Unknown）、`recognize_faces`（对 Target_Figure 逐张识别） |
| `ocr.py`         | 可选功能：用 RapidOCR 提取照片里的文字（默认关闭），结果存`ocr_result.csv`                                                                                                                                                               |
| `utils.py`       | 解决 Windows 上 OpenCV 不支持中文路径的问题，用`np.fromfile` + `cv2.imdecode` 读写图片                                                                                                                                                 |
| `visualize.py`   | 在图片上画人脸框、5 个关键点、姓名+相似度标签（绿=已识别，红=未知）                                                                                                                                                                        |
| `__init__.py`    | 包入口，统一导出函数                                                                                                                                                                                                                       |

### 2. 入口 / 编排

| 文件           | 职责                                                                                                                                                                                                                                                         |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `main/main.py`    | 命令行入口：加载模型 → 录入 Ref_Figure 人脸库 → 识别 Target_Figure → 输出`00_程序人脸识别结果.xlsx`，并依次生成表1~表10（均写入 output/）。人脸库向量带缓存（`Ref_Figure/face_db_cache.pkl`，随人脸库存放）：Ref_Figure 图片未增删改时自动复用缓存，跳过向量计算 |
| `web_show/web_app.py` | Flask Web 交互界面（`AI_PY312` 环境启动，浏览器打开 `http://localhost:5000`）。苹果风格白蓝主题分步向导：①人脸识别 ②上传输入表 ③人工复核未识别人员 ④生成项目信息表（04_工地项目统计+06/07 周表 → 000_项目信息表，含确认弹窗）⑤生成表格（表1 预览高亮异常；05/06 网页内联展示错误文档+可编辑表格并写回）⑥完成下载（合并文件「08_09_10_最终考勤表.xlsx」一个文件三个子表）。识别在后台线程运行、前端实时轮询日志 |

### 3. 表生成脚本（generate_*）

| 文件 | 输入 → 输出 | 说明 |
| ---- | ------------ | ---- |

> 表1~表10 的生成逻辑全部在 [face_app/generate_table.py](face_app/generate_table.py)，函数为 `get_table1` ~ `get_table8_9_10`，由 [main/main.py](main/main.py) 的 `main()` 依次调用（也可在代码里直接 `from face_app import get_tableN` 调用）。

| 函数（入口脚本） | 输入 → 输出 | 说明 |
| ---------------- | ------------ | ---- |

> 目录规范：所有输入表在 `input/`，所有生成文件在 `output/`（均为小写）。

| 函数                     | 输入 → 输出                                                                                                | 说明                                                                                                                                                         |
| ------------------------ | ----------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `get_table1`           | input/01_照片台账表 →**output/01_今日相机出工信息提取表**                                            | 按人汇总开工/收工时间（开工取最早、收工取最晚），判断"开工未发 / 开工晚发 / 收工未发 / 半天换场"，按收工时间自动测算加班时长（17:00 为基准），异常单元格高亮 |
| `get_table2`           | input/02_工作安排表 →**output/02_工作安排_提取表**                                                   | 解析"包工头N人（实际名单）"等格式，得到每人出工安排（出工 / 请假 / 外协未到岗 / 安排休息）及所属项目                                                         |
| `get_table3`           | output/00_程序人脸识别结果.xlsx →**output/03_出工照片人脸识别结果表**                                | 从文件名解析拍摄人姓名、拍摄时间、人脸序列号，关联识别结果                                                                                                   |
| `get_table4`           | output/03_出工照片人脸识别结果表 →**output/04_出工照片识别出工人表**                                 | 把"拍摄人本人 + 识别出的人"按人汇总时间点，预留 5 个时间列                                                                                                   |
| `get_table5`           | output/01_今日相机出工信息提取表 + output/04_出工照片识别出工人表 →**output/05_该日出工人员表 + 核对信息错误文档1** | 对比表1（台账申报）与表4（人脸识别）：有异常时额外输出 `核对信息错误文档1.xlsx` 供人工核对；无异常直接输出 `05_该日出工人员表.xlsx`                           |
| `get_table6`           | output/05_该日出工人员表 + output/02_工作安排_提取表 →**output/06_全体人员出工情况表 + 核对信息错误文档2** | 对比 05_（实际）与表2（计划）：安排出工未出工→漏报/缺勤，安排休息却出工→安排不符，出工无安排→安排遗漏，项目不匹配→错报；同时用 002 补出勤统计简称，有异常输出错误文档2 |
| `get_table7`           | output/06_全体人员出工情况表 + input/03_人员分类表 →**output/07_表7出工地点及时长统计表**                                      | 补上类别、所属人员、上午/下午出工地点、加班时长，附带异常提醒列                                                                                              |
| `get_table8_9_10`      | output/表7 + input/考勤模板 →**output/08_09_10_最终考勤表.xlsx（一个文件三个子表）**                                    | 按类别分流填表（公司人员→表8、外协1/临时工→表9、外协2→表10），填完直接保存为一个文件、三个子表（表8/表9/表10），合并单元格格式保留，末尾加"异常提醒"列 |

> 异常检验1/2 均已合并为 `get_table5` / `get_table6`（见上表），已无独立异常检验脚本。

## 环境要求与安装

```bash
pip install -r requirements.txt
```

依赖（见 `requirements.txt`）：

- `flask`：Web 界面
- `pandas` + `openpyxl`：Excel 读写
- `insightface`：人脸识别引擎
- `onnxruntime`：InsightFace 推理后端
- `opencv-python`、`pillow`、`numpy`：图像处理

> **GPU 加速（可选）**：确认环境支持 CUDA / DirectML 后，可将 `main/main.py` 中的 `PROVIDERS` 手动改为 `["CUDAExecutionProvider", "CPUExecutionProvider"]`（默认自动检测）。
>
> **OCR 功能（可选）**：如需提取照片文字，先 `pip install rapidocr_onnxruntime`，再将 `main/main.py` 中的 `OCR_ENABLED` 改为 `True`。
