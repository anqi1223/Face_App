# 人脸识别考勤系统

基于 **人脸识别 + 拍照台账** 的工地考勤处理系统。

每天工人开工 / 收工时用相机拍一张照片（照片文件名含拍摄人姓名和拍摄时间，如 `储少球 2026_06_08 09_05_17 开(收)工汇报.jpg`），系统通过 **InsightFace** 人脸识别确认照片中的人员，再结合工作安排表、项目信息表等 Excel，自动生成一套考勤报表（表1 ~ 表10），并对 **缺勤、多报、漏报、项目不匹配** 等异常情况自动检验，输出"人工复核提示文档"供管理员核对。

│   └── index.html               #   4 个步骤的操作界面

├── test.py                      # 环境自检：检查 onnxruntime / GPU Provider
├── requirements.txt             # 依赖清单

├── input/                        # 输入表（均在 input/ 目录，详见下方"输入表"）

## 核心数据流

```
Ref_Figure/ 人脸库  +  Target_Figure/ 当日照片
   │  main.py  人脸识别 (InsightFace)
   ▼
00_程序人脸识别结果.xlsx
   │
   ├─ get_table3 → 表3 ─ get_table4 → 表4 ──┐
照片台账表 ─ get_table1 → 表1 ─────────────┤
工作安排表 ─ get_table2 → 表2 ─────────────┘
                                                    get_table5
                                                    ↓ 表1 vs 表4
                                   05_该日出工人员表 + 核对信息错误文档1
                                                    get_table6
                                                    ↓ 05_ vs 表2
                                   06_全体人员出工情况表 + 核对信息错误文档2
06_ + 03_人员分类表 ─ get_table7 → 表7 出工地点及时长统计表
表7 + 考勤模板 ─ get_table8_9_10 → 表8/表9/表10 最终考勤表
```

> **注意**：表5（05_该日出工人员表）、表6（06_全体人员出工情况表）由 `get_table5` / `get_table6` 自动生成，不再需要手工上传；`核对信息错误文档1/2` 在有异常时生成，供人工核对修正。

## 程序职责详解

### 1. 人脸识别核心包 `face_app/`

| 文件               | 职责                                                                                                                                                                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `face_engine.py` | InsightFace 封装：`init_face_app`（加载 `buffalo_l` 模型）、`enroll_faces`（录入 Ref_Figure 人脸库）、`match_face`/`cosine_similarity`（余弦相似度比对，低于阈值判为 Unknown）、`recognize_faces`（对 Target_Figure 逐张识别） |
| `ocr.py`         | 可选功能：用 RapidOCR 提取照片里的文字（默认关闭），结果存`ocr_result.csv`                                                                                                                                                               |
| `utils.py`       | 解决 Windows 上 OpenCV 不支持中文路径的问题，用`np.fromfile` + `cv2.imdecode` 读写图片                                                                                                                                                 |
| `visualize.py`   | 在图片上画人脸框、5 个关键点、姓名+相似度标签（绿=已识别，红=未知）                                                                                                                                                                        |
| `__init__.py`    | 包入口，统一导出函数                                                                                                                                                                                                                       |

### 2. 入口 / 编排

| 文件           | 职责                                                                                                                                                                                                                                                         |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `main.py`    | 命令行入口：加载模型 → 录入 Ref_Figure 人脸库 → 识别 Target_Figure → 输出`00_程序人脸识别结果.xlsx`，并依次生成表1~表10（均写入 output/）。人脸库向量带缓存（`output/face_db_cache.pkl`）：Ref_Figure 图片未增删改时自动复用缓存，跳过向量计算 |
| `web_app.py` | Flask Web 服务（`python web_app.py` 后浏览器打开 `http://localhost:5000`）。把整个流程分成 4 个步骤，每个步骤可上传表格、逐个或一键执行脚本，并展示已生成文件、可下载                                                                                    |
| `test.py`    | 环境自检：检查 onnxruntime 是否装好、有没有 GPU Provider（CUDA/DirectML）                                                                                                                                                                                    |

### 3. 表生成脚本（generate_*）

| 文件 | 输入 → 输出 | 说明 |
| ---- | ------------ | ---- |

> 表1~表10 的生成逻辑全部在 [face_app/generate_table.py](face_app/generate_table.py)，函数为 `get_table1` ~ `get_table8_9_10`，由 [main.py](main.py) 的 `main()` 依次调用（也可在代码里直接 `from face_app import get_tableN` 调用）。

| 函数（入口脚本） | 输入 → 输出 | 说明 |
| ---------------- | ------------ | ---- |

> 目录规范：所有输入表在 `input/`，所有生成文件在 `output/`（均为小写）。

| 函数                     | 输入 → 输出                                                                                                | 说明                                                                                                                                                         |
| ------------------------ | ----------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `get_table1`           | input/01_照片台账表 →**output/01_今日相机出工信息提取表**                                            | 按人汇总开工/收工时间（开工取最早、收工取最晚），判断"开工未发 / 开工晚发 / 收工未发 / 半天换场"，按收工时间自动测算加班时长（17:00 为基准），异常单元格高亮 |
| `get_table2`           | input/02_工作安排表 →**output/02_工作安排_提取表**                                                   | 解析"包工头N人（实际名单）"等格式，得到每人出工安排（出工 / 请假 / 外协未到岗 / 安排休息）及所属项目                                                         |
| `get_table3`           | output/00_程序人脸识别结果.xlsx →**output/03_出工照片人脸识别结果表**                                | 从文件名解析拍摄人姓名、拍摄时间、人脸序列号，关联识别结果                                                                                                   |
| `get_table4`           | output/03_出工照片人脸识别结果表 →**output/04_出工照片识别出工人表**                                 | 把"拍摄人本人 + 识别出的人"按人汇总时间点，预留 5 个时间列                                                                                                   |
| `get_table5`           | output/01_今日相机出工信息提取表 + output/04_出工照片识别出工人表 →**output/05_该日出工人员表 + 核对信息错误文档1** | 对比表1（台账申报）与表4（人脸识别）：有异常时额外输出 `核对信息错误文档1.xlsx` 供人工核对；无异常直接输出 `05_该日出工人员表.xlsx`                           |
| `get_table6`           | output/05_该日出工人员表 + output/02_工作安排_提取表 →**output/06_全体人员出工情况表 + 核对信息错误文档2** | 对比 05_（实际）与表2（计划）：安排出工未出工→漏报/缺勤，安排休息却出工→安排不符，出工无安排→安排遗漏，项目不匹配→错报；同时用 002 补出勤统计简称，有异常输出错误文档2 |
| `get_table7`           | output/06_全体人员出工情况表 + input/03_人员分类表 →**output/07_表7出工地点及时长统计表**                                      | 补上类别、所属人员、上午/下午出工地点、加班时长，附带异常提醒列                                                                                              |
| `get_table8_9_10`      | output/表7 + input/考勤模板 →**output/表8/9/10 三张最终考勤表**                                      | 按类别分流填表（公司人员→表8、外协1/临时工→表9、外协2→表10），从模板 sheet 复制格式和合并单元格，保留原名顺序，末尾加"异常提醒"列                         |

> 异常检验1/2 均已合并为 `get_table5` / `get_table6`（见上表），已无独立异常检验脚本。

### 5. 前端页面

## 各类 Excel 的角色

### 输入表

> 输入表全部位于 `input/` 目录（web 界面上传时也会保存到此处）。

| 文件（位于 input/）            | 用途                                                                                                                |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| `03_人员分类表.xlsx`         | 人员分类（姓名 / 类别 / 所属人员），类别决定最终填入表8 / 表9 / 表10（原 001人员分类表）                            |
| `04_项目信息表.xlsx`         | 项目信息，提供"工作安排简称 → 出勤统计简称"的匹配映射（原 002项目信息表）                                            |
| `01_照片台账表.xlsx`         | 当日相机出工照片台账（拍摄人 / 人员名单 / 拍摄时间 / 汇报类型 / 工程名称 / 拍摄地点 / 存在问题 / 加班时长），需上传 |
| `02_工作安排表.xlsx`         | 当日工作安排（项目 + 负责人 + 人员 + 特殊状态名单），需上传                                                         |
| `05_工程与外协考勤表模板.xlsx`  | 内含"表8工程考勤表 / 表9外协考勤表1 / 表10外协考勤表2"三个模板 sheet                                                |

### 中间结果 / 最终成果

> 所有生成文件统一写入 [output/](output/) 目录。

- 人脸识别：`output/00_程序人脸识别结果.xlsx`、`output/ocr_result.csv`（OCR 开启时）、`output/` 下标注图
- 中间表（均在 `output/`）：`01_今日相机出工信息提取表`、`02_工作安排_提取表`、`03_出工照片人脸识别结果表`、`04_出工照片识别出工人表`、`05_该日出工人员表`、`06_全体人员出工情况表`、`07_表7出工地点及时长统计表`、`核对信息错误文档1/2`
- **最终成果**（均在 `output/`）：`08_表8工程考勤表.xlsx`、`09_表9外协考勤表1.xlsx`、`10_表10外协考勤表2.xlsx`

> 说明：`待确认表1.xlsx`、`所有表格.xlsx` 没有脚本生成，属早期版本或手工整理的遗留文件。

## 环境要求与安装

```bash
pip install -r requirements.txt
```

依赖（见 `requirements.txt`）：

- `flask`：Web 界面
- `pandas` + `openpyxl`：Excel 读写
- `insightface`：人脸识别引擎
- `onnxruntime`：InsightFace 推理后端
- `opencv-python`、`pillow`、`numpy`：图像处理

> **GPU 加速（可选）**：先运行 `python test.py` 确认 CUDA / DirectML 环境可用，再将 `main.py` 中的 `PROVIDERS` 改为 `["CUDAExecutionProvider", "CPUExecutionProvider"]`。
>
> **OCR 功能（可选）**：如需提取照片文字，先 `pip install rapidocr_onnxruntime`，再将 `main.py` 中的 `OCR_ENABLED` 改为 `True`。

## 使用方法

### 方式一：Web 界面（推荐）

```bash
python web_app.py
```

浏览器打开 `http://localhost:5000`，按页面上的 **4 个步骤** 依次操作：

1. **基础信息处理**：上传 001/002/工作安排/照片台账表 → 人脸识别 → 生成表1~表5
2. **生成表6/异常检验2**：无上传，直接生成 06_全体人员出工情况表 + 核对信息错误文档2
3. **生成表7**：无上传，直接生成表7
4. **生成表8/9/10**：上传考勤模板 → 生成最终考勤表

### 方式二：命令行

```bash
# 0. 环境自检（可选）
python test.py

# 1. 人脸识别 + 表1~表10 全部生成
#    需要：Ref_Figure 人脸库 + Target_Figure 待识别照片 + input/ 下输入表
python main.py

# 2. 根据 output/核对信息错误文档1/2 人工核对修正后，重新跑 main.py
```

## 图片目录使用规范

| 目录               | 规范                                                                                                      |
| ------------------ | --------------------------------------------------------------------------------------------------------- |
| `Ref_Figure/`    | 每张照片一个人，命名`姓名.jpg` 或 `姓名_01.jpg`（同一人多张可加序号），系统自动按文件名录入人脸库     |
| `Target_Figure/` | 当日出工照片，文件名建议格式：`姓名 YYYY_MM_DD HH_MM_SS 开(收)工汇报.jpg`，程序按文件名解析拍摄人和时间 |
